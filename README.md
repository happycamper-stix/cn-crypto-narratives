# CN Crypto Narratives

Living glossary decoding Chinese crypto lingo, sayings, coin names, and tickers into
English — capturing what the term *actually means* (wordplay, homophones, memes,
cultural context), not the literal translation.

## Structure
- `glossary/` — one atomic note per term/saying (`ge-jiu-cai.md`, `da-bing.md`, …)
- `narratives/` — meta-narrative notes (national coins, inscription mania, launchpad naming conventions)
- `patterns/` — decoding mechanics: homophone plays, number substitution, animal/food metaphors
- `references/` — source glossaries, articles, accounts worth following
- `logs/` — session logs

## Glossary note format
Each term note carries: Chinese characters, pinyin, literal translation, actual
meaning, origin/wordplay mechanics, example usage, and wikilinks to related terms
and the pattern that generates it.
