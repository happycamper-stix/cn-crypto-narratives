# CN Crypto Narratives

Living glossary decoding Chinese crypto lingo, sayings, coin names, and tickers into
English — capturing what the term *actually means* (wordplay, homophones, memes,
cultural context), not the literal translation.

## Structure
- `patterns/` — the generative mechanics: how the slang gets made
- `glossary/` — term tables by category + atomic notes for rich etymologies
- `narratives/` — meta-narratives, eras, and ecosystems the lingo lives in
- `references/` — sources, live feeds, KOL directory, methodology
- `logs/` — session logs
