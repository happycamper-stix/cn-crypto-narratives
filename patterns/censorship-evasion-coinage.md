# Censorship-Evasion Coinage (隐语 / 黑话)

## Context
Two regulatory shocks shaped the lexicon: 九四 (Sept 4, 2017 — PBoC bans ICOs and
domestic exchanges) and the May–Sept 2021 crackdown (mining ban, all crypto
transactions declared illegal). On WeChat/Weibo, writing 比特币 or 卖币 in the
wrong context risks group bans and keyword flags. The community's answer was a
full replacement vocabulary — the reason so much CN crypto slang is *food*: bread,
chives, candy are unfilterable.

## Mechanics
- **Innocent-object substitution**: 大饼 (dàbǐng, "big flatbread") = BTC; 姨太/E太
  = ETH; 糖果 (tángguǒ, "candy") = free airdropped tokens. A filter scanning for
  financial keywords sees a breakfast conversation. See [[da-bing]].
- **Letter/character swap**: 币 → B or 比 ("出B", "屯B"); USDT → U. Mixing Latin
  letters into Chinese text breaks naive keyword matching.
- **Euphemized verbs**: 上车 ("get on the bus") = buy in; 下车 = sell;
  出金/入金 ("money out/in") borrowed from forex; 搬砖 ("moving bricks") =
  cross-exchange arbitrage — all readable as ordinary life or day-labor talk.
- **Homophone shielding**: sensitive names get sound-alikes, the same 谐音
  mechanism used across the Chinese internet (河蟹 for 和谐 "harmonized" =
  censored). See [[homophone-wordplay]].
- **Platform migration markers**: post-2021, "科学上网" (VPN use), 场外/OTC (
  peer-to-peer USDT desks), and 出海 ("going overseas") became routine vocabulary
  because the activity itself moved offshore.
- **Numbered trauma dates as shorthand**: 94, 312, 519 compress unspeakable events
  into innocuous digits — see [[number-slang]].

## Decoding heuristic
If a Chinese crypto term seems weirdly domestic (food, buses, bricks, candy),
assume it was chosen to be invisible to keyword filters, and map it to the
financial action it disguises. The blander the surface, the more sensitive the
referent.
