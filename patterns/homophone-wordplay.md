# Homophone Wordplay (谐音梗, xiéyīn gěng)

## Context
The single biggest reason Chinese crypto names don't translate: Mandarin is
homophone-dense, so names/tickers are often puns on sound, not meaning. A literal
translation loses the joke entirely.

## Mechanics
- **Sound-alike renaming of majors**: ETH → 姨太 (yítài, "concubine/second wife")
  because "Ethereum" transliterates as 以太 (yǐtài). Extended into the harem joke:
  大姨太 ETH, 二姨太 ETC — see [[da-yi-tai]].
- **Censorship evasion**: sensitive or banned words swapped for homophones, a habit
  imported from mainland internet culture where crypto talk is policed.
- **Ticker puns**: memecoin tickers picked so the pinyin reading lands a joke or an
  auspicious phrase invisible to English readers.
- **Partial transliteration + meaning**: names chosen so the transliteration is
  simultaneously a real Chinese word with its own (often mocking or lucky) meaning.

## Decoding heuristic
When a Chinese coin name seems random: (1) read it aloud in Mandarin pinyin,
(2) look for a same-sounding common word or phrase, (3) check if it's an auspicious
number/phrase — see [[number-slang]].
