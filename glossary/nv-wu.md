# 女巫 (nǚwū) — "The Witch"

**Literal:** witch. **Actual:** a Sybil attacker — one person posing as many wallets
to multiply an airdrop.

## Etymology
A double translation accident. "Sybil attack" comes from *Sybil* (1973), a book
about a woman with multiple personalities; Chinese rendered the attack as 女巫攻击
— "witch attack" — because Sybil sounds like a sorceress name. So CN airdrop
discourse is full of witchcraft imagery English never had: getting your wallets
disqualified is 被女巫了 ("got witched"), and projects run 女巫检测 (witch-hunts,
literally) with clustering analysis before token generation.

The irony: in 撸毛 (wool-plucking, see [[community-roles]]) culture, *everyone* is
a bit of a witch. Studios run 万号 (ten-thousand-account) farms; solo farmers debate
how many wallets stay under the detection radar. Guides teach 防女巫 hygiene — fresh
funding paths, varied timing, no wallet-to-wallet transfers — an entire folk
anti-forensics curriculum.

## Usage
- 这批号全被标记女巫 — "this batch of accounts all got flagged as Sybils"
- 防女巫攻略 — anti-Sybil-detection guide
